# Burrow Skills

*Knowledge today. Stronger tomorrow.*

Meet **Tinker and Trixie**, the App Goblins of Burrow Skills. This library gives agents reusable operating instructions for Burrow and its integrations. Burrow supplies its own operating instructions automatically. The forthcoming managed-skills system extends this to companion skills declared by loaded mods, with automatic refresh and read-only runtime copies. You can inspect the public instructions before trusting them.

A skill explains **how to approach work**. It does not install a mod, connect a host, grant access, or authorize an action. Burrow's live tools and your configured permissions still determine what an agent can do.

## Read the instructions first

The [public repository](https://github.com/GoblinKing-Burrow/Burrow-Skills) exposes the exact skill files for review. Read what they ask an agent to do, compare it with the installed tools, and check later changes too. Public visibility helps you evaluate instructions; it is not a blanket safety guarantee.
